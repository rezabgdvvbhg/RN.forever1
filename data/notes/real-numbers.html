بر اساس کتاب ریاضی نهم و کتاب تکمیلی ریاضی نهم

درس اول: عددهای گویا

۱. تعریف عدد گویا

هر عددی که بتوان آن را به صورت کسر \(\frac{a}{b}\) نوشت، به‌طوری که \(a\) و \(b\) عددهایی صحیح و \(b \neq 0\) باشند، یک عدد گویا است. مجموعهٔ عددهای گویا را با \(\mathbb{Q}\) نمایش می‌دهیم:

\[\mathbb{Q} = \left\{ \frac{a}{b} \mid a,b \in \mathbb{Z},\ b \neq 0 \right\}\]

۲. نمایش اعشاری عددهای گویا

هر عدد گویا را می‌توان به صورت اعشاری نوشت. این نمایش یکی از حالت‌های زیر است:

  • مختوم: مانند \(\frac{3}{4}=0/75\)
  • متناوب ساده: مانند \(\frac{1}{3}=0/333\cdots=0/\overline{3}\)
  • متناوب مرکب: مانند \(\frac{1}{6}=0/1666\cdots=0/1\overline{6}\)

نکته: اگر پس از ساده کردن کسر، مخرج فقط شمارنده‌های اول ۲ و ۵ را داشته باشد، نمایش اعشاری مختوم است.

۳. تبدیل اعشاری به کسری

روش دانا:

\[0/\overline{72} = \frac{72}{99}\]

روش مانا:

\[a = 0/\overline{72} \Rightarrow 100a = 72/\overline{72} \Rightarrow 99a = 72 \Rightarrow a = \frac{72}{99}\]

مثال متناوب مرکب:

\[1/325\overline{7} = \frac{13125}{9900}\]

۴. عملیات روی عددهای گویا

  • جمع و تفریق: با مخرج مشترک.
  • ضرب: \(\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}\)
  • تقسیم: \(\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}\)

۵. ترتیب و مقایسه

برای مقایسه دو کسر، می‌توان از روش‌های زیر استفاده کرد:

  • مخرج مشترک
  • تبدیل به اعشاری
  • مقایسه با عدد ۱
  • ضرب متقاطع

مثال: مقایسه \(\frac{3}{5}\) و \(\frac{5}{9}\)

\[\frac{3}{5} = 0/6,\quad \frac{5}{9} \approx 0/555 \Rightarrow \frac{3}{5} > \frac{5}{9}\]

۶. چگالی اعداد گویا (بخش تکمیلی)

بین هر دو عدد گویا، بی‌شمار عدد گویا وجود دارد. مثال: بین \(\frac{1}{3}\) و \(\frac{1}{2}\) می‌توان نوشت:

\[\frac{1}{3} < \frac{5}{12} < \frac{1}{2}\]

روش میانگین:

\[\frac{\frac{1}{3}+\frac{1}{2}}{2} = \frac{5}{12}\]

۷. طول دورهٔ گردش (بخش تکمیلی)

اگر در نمایش اعشاری یک عدد گویا، ارقامی به‌طور متناوب تکرار شوند، به تعداد ارقام تکرارشونده طول دورهٔ گردش می‌گویند. مثال:

\[0/\overline{156} \Rightarrow \text{طول دوره}=3\]
\[3/43\overline{98} \Rightarrow \text{طول دوره}=2\]

درس دوم: عددهای حقیقی

۱. اعداد گنگ

عددهایی که گویا نیستند، گنگ نامیده می‌شوند. مانند \(\sqrt{2}\)، \(\sqrt{3}\)، \(\pi\). مجموعهٔ اعداد گنگ را با \(\mathbb{Q}'\) نمایش می‌دهیم.

۲. ریشه‌گیری

  • ریشه دوم عدد \(a \ge 0\): عددی مانند \(x\) که \(x^2 = a\).
\[\sqrt{a} \ge 0,\quad (-\sqrt{a})^2 = a\]
  • ریشه سوم: \(\sqrt[3]{a}\) برای هر عدد حقیقی.

مثال:

\[\sqrt{9}=3,\quad \sqrt[3]{-8}=-2\]

۳. مجموعهٔ اعداد حقیقی

\[\mathbb{R} = \mathbb{Q} \cup \mathbb{Q}'\]

هر عدد حقیقی یا گویا است یا گنگ.

۴. رابطهٔ مجموعه‌ها

\[\mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}\]
\[\mathbb{Q} \cap \mathbb{Q}' = \varnothing,\quad \mathbb{Q} \cup \mathbb{Q}' = \mathbb{R}\]

۵. نمایش روی محور

هر عدد حقیقی را می‌توان روی محور اعداد نشان داد. برای نمایش \(\sqrt{2}\) از قضیهٔ فیثاغورس استفاده می‌کنیم: مثلث قائم‌الزاویه با اضلاع ۱ و ۱، وتر \(\sqrt{2}\) است.

۶. تقریب اعداد گنگ

\[\sqrt{2} \approx 1/4142,\quad \pi \approx 3/1415\]

برای محاسبهٔ دقیق‌تر، از روش‌های عددی مانند تقسیم بازه استفاده می‌شود.

۷. عملیات با رادیکال‌ها

جمع و تفریق: فقط رادیکال‌های متشابه را می‌توان جمع کرد.

\[2\sqrt{3} + 5\sqrt{3} = 7\sqrt{3}\]

ضرب و تقسیم:

\[\sqrt{a} \times \sqrt{b} = \sqrt{ab}\]
\[\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}\]

گویا کردن مخرج:

\[\frac{2}{\sqrt{3}} = \frac{2}{\sqrt{3}} \times \frac{\sqrt{3}}{\sqrt{3}} = \frac{2\sqrt{3}}{3}\]

۸. اتحادهای مهم

\[\sqrt{a^2} = |a|\]
\[(\sqrt{a})^2 = a \quad (a \ge 0)\]
\[\sqrt{a^2 b} = |a|\sqrt{b}\]

درس سوم: قدر مطلق و محاسبه تقریبی

۱. تعریف قدر مطلق

فاصلهٔ عدد \(a\) از صفر روی محور اعداد را قدر مطلق \(a\) می‌نامیم و با \(|a|\) نشان می‌دهیم:

\[|a| = \begin{cases} a & a \ge 0 \ -a & a < 0 \end{cases}\]

مثال:

\[|5|=5,\quad |-3|=3,\quad |0|=0\]

۲. ویژگی‌های قدر مطلق

\[|ab| = |a||b|\]
\[\left| \frac{a}{b} \right| = \frac{|a|}{|b|} \quad (b \neq 0)\]
\[|a+b| \le |a| + |b|\]
\[|a| = |-a|\]

۳. معادلات قدر مطلق

\[|x| = a \Rightarrow x = a \text{ یا } x = -a \quad (a \ge 0)\]

مثال:

\[|x-2| = 5 \Rightarrow x-2=5 \text{ یا } x-2=-5 \Rightarrow x=7 \text{ یا } x=-3\]

۴. نامعادلات قدر مطلق

\[|x| < a \Rightarrow -a < x < a \quad (a > 0)\]
\[|x| > a \Rightarrow x > a \text{ یا } x < -a \quad (a > 0)\]

مثال:

\[|x-1| < 3 \Rightarrow -3 < x-1 < 3 \Rightarrow -2 < x < 4\]

۵. محاسبه تقریبی

برای محاسبهٔ تقریبی، عدد را با تقریب کم‌تر بیان می‌کنیم. خطا: تفاوت مقدار واقعی و تقریبی.

مثال:

\[\sqrt{2} \approx 1/4 \Rightarrow \text{خطا} = |1/4142 - 1/4| = 0/0142\]

۶. ریشه دوم و قدر مطلق

\[\sqrt{x^2} = |x|\]

مثال:

\[\sqrt{(-3)^2} = |-3| = 3\]
\[\sqrt{(2-\sqrt{5})^2} = |2-\sqrt{5}| = \sqrt{5}-2\]

تمرین‌های ترکیبی از هر دو کتاب

  1. حاصل عبارت‌های زیر را به‌دست آورید:
\[\sqrt{(-7)^2} = | -7 | = 7\]
\[\sqrt{(3-\pi)^2} = |3-\pi| = \pi - 3\]
  1. مخرج کسر زیر را گویا کنید:
\[\frac{5}{2\sqrt{3}} = \frac{5}{2\sqrt{3}} \times \frac{\sqrt{3}}{\sqrt{3}} = \frac{5\sqrt{3}}{6}\]
  1. اگر \(a<0\)، حاصل \(\sqrt{a^2} + \sqrt[3]{a^3}\) را ساده کنید:
\[\sqrt{a^2} = |a| = -a,\quad \sqrt[3]{a^3} = a \Rightarrow -a + a = 0\]
  1. طول دورهٔ گردش کسر \(\frac{1}{7}\) را بیابید:
\[\frac{1}{7} = 0/\overline{142857} \Rightarrow \text{طول دوره}=6\]
  1. مجموعهٔ جواب نامعادله \(|2x-1| \le 5\) را روی محور اعداد نمایش دهید:
\[-5 \le 2x-1 \le 5 \Rightarrow -4 \le 2x \le 6 \Rightarrow -2 \le x \le 3\]
