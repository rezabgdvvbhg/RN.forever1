# رادیکال RN — پلتفرم آموزشی ریاضی نهم (نسخهٔ ۵)

سایت آموزشی فارسی و راست‌چین با جزوهٔ کامل هشت فصل، ابزارهای تعاملی هر فصل، سامانهٔ فیلم‌های آموزشی و پنل معلمان (منابع، بانک سؤال، آزمون‌ساز، پاورپوینت‌ساز).
نام داخلی پروژه: `stark` · سازنده: **رضا علیمحمدی**

## نسخهٔ ۵ — ارتقای اصلی (مقدمه، سه‌بعدی زمینه‌ای، یادمان ریاضیات، بازی ماجراجویی، جارویس RN)
> معماری واقعی پروژه جاوااسکریپت ساده + Three.js است (نه React/Vite)؛ همهٔ موارد با همین معماری و بدون وابستگی تازه اجرا شد. برای بازگشت، پیش از شروع یک commit در git ثبت شد (`checkpoint v4 before master upgrade`)؛ پوشهٔ `.git` در ZIP نیست. جزئیات هر فاز: `UPGRADE_PROGRESS.md`.

- **مقدمهٔ سینمایی:** ≈ ۴٫۸ ثانیه، فقط بار اول روی `/`، دکمهٔ «رد شدن» و Esc، حالت کاهش حرکت آن را نشان نمی‌دهد، بدون WebGL جایگزین SVG/CSS دارد، صدا ندارد. **پیش‌نمایش (توسعه):** `?intro=1` را به نشانی اضافه کنید، یا در کنسول `RN_INTRO.replay()`. فایل‌ها: `js/intro-gate.js`، `js/intro.js`، `css/intro.css`.
- **سه‌بعدی زمینه‌ای:** `js/rn3d.js` برای هر فصل یک صحنهٔ ریاضی‌محور می‌سازد (دو دایره و عدسی اشتراک، محور اعداد با √۲ و π، مثلث ۳-۴-۵ با مربع‌های ۹ و ۱۶ و ۲۵، مکعب ۳×۳×۳، تجزیهٔ \((a+b)^2\)، خط و نقطهٔ متحرک، کسر حروف‌چینی‌شده و حفرهٔ دامنه، استوانه/مخروط/کره با نسبت ۳:۱:۲). فقط وقتی دیده می‌شود رندر می‌کند، ۳۰fps، DPR ≤ ۱٫۲۵، آزادسازی کامل؛ موبایل و بدون WebGL: جایگزین CSS.
- **یادمان ریاضیات (`/history`):** هفت چهره روی یک صخرهٔ اصیل (نه کپی هیچ یادبود)، در موبایل فهرست عمودی. برای هر شخص: بخش‌های زندگی‌نامه، آثار، دستاورد با برچسب «مستند/منسوب»، و **پیوند فصل‌ها با دو نوع برچسب: «ارتباط تاریخی مستقیم» یا «ارتباط آموزشی»**.
- **ویدیو/انیمیشن آیندهٔ تاریخچه:** در `data/history.json` آرایهٔ `media` هر شخص را پر کنید؛ بدون ورودی معتبر هیچ کنترلی نمایش داده نمی‌شود، و اگر فایل وجود نداشته باشد نیز پنهان می‌ماند. نمونه (فایل را در `files/media/` بگذارید):
```json
"media":[{"id":"euclid-elements","type":"animation","src":"/files/media/euclid-elements.mp4","poster":"/files/media/euclid-elements.webp","title":"اصول اقلیدس در ۲ دقیقه","duration":"۰۲:۰۰","caption":"ساختار تعریف ← اصل موضوع ← برهان","transcript":"…","chapter":"geometry-reasoning"}]
```
`type`: `animation` ، `video` یا `audiovisual`؛ به‌جای `src` می‌توان `embed:{"type":"youtube","id":"…"}` یا آپارات داد. فقط مسیرهای `/assets/` و `/files/` یا `https://` پذیرفته می‌شود.
- **«پروندهٔ صفر» (`/games/zero-file`):** ماجراجویی ۲٫۵بعدی کوتاه با سه تالار و سه معمای فیزیکی (پل سنگ‌های گویا/گنگ، جعبه‌ها و صفحه‌های توان/ریشه/قدر مطلق، پرتوی لیزر برای شیب و عرض از مبدأ)، مأموریت، دفترچه، راهنما، ریست، توقف، ذخیرهٔ پیشرفت، رتبه (A تا C) و ۱۸ گونه. کنترل: جهت‌ها یا W A S D، E تعامل، H راهنما، R ریست، J دفترچه، P/Esc توقف؛ در لمس دکمه‌های صفحه. معماری: `js/zf-core.js` منطق خالص (قابل اجرا در Node)، `js/zf-ui.js` رندر/ورودی؛ برای بازی‌های بعدی می‌توان همین الگو (هستهٔ خالص + رندر + آزمون خودکار) را تکرار کرد.
- **جارویس RN:** دستیار آفلاین فارسی در گوشهٔ چپ پایین. پایگاه دانش: `data/jarvis/*.json` (۷۵ نیت: ناوبری، راهنمای سایت، تاریخ، تعریف‌ها و فرمول‌های هر هشت فصل)، موتور قطعی بدون شبکه: `js/jarvis-engine.js` (نرمال‌سازی فارسی/عربی، امتیازدهی، آستانهٔ اطمینان، حالت یادگیری با «اول راهنمایی»). افزودن دانش: یک آبجکت به فایل JSON مناسب اضافه کنید (`id`, `domain`, `keys`, `examples`, `text`, `links`, `follow`)؛ یا `tools/build-jarvis-kb.py` را ویرایش و اجرا کنید. جارویس یک مدل زبانی عمومی نیست و دربارهٔ چیزهای خارج از پایگاه دانش صادقانه می‌گوید نمی‌داند.

### آزمودن
`npm test` (بدون وابستگی اضافه): ۸۶۳ فرمول، ۸۲٬۸۰۰ نمونهٔ سؤال، بانک آزمون، تاریخچه، منطق بازی‌ها، **حل خودکار ۱۸ گونهٔ پروندهٔ صفر از ابتدا تا انتها**، **۱۳۲ بررسی جارویس** (عبارت‌های دقیق، بازنویسی‌ها، ي/ك عربی، ارقام، ناشناخته، خالی، مبهم، تعارض، زمینه، حالت یادگیری، آفلاین‌بودن)، صحنه‌های سه‌بعدی بدون GPU، PPTX و سرور.
`npm i --no-save jsdom canvas && npm run test:ui` — آزمون رابط (مقدمه در آزمون‌ها به‌دلیل مدل‌سازی «کاهش حرکت» رد می‌شود؛ برای دیدنش با `?intro=1` در مرورگر امتحان کنید). بدون `canvas` هم کار می‌کند ولی آزمون بازی با بوم ساختگی اجرا می‌شود.

### محدودیت‌های صادقانهٔ نسخهٔ ۵
- مقدمه، صحنه‌های سه‌بعدی و ظاهر یادمان در مرورگر واقعی دیده نشد. فقط ساخت هندسه (بدون GPU)، بوم ۲بعدیِ بازی (با node-canvas) و منطق/رابط (jsdom) آزموده شد؛ عملکرد روی Intel HD 520 اندازه‌گیری نشد (فقط با طراحی سبک: ۳۰fps، DPR ≤ ۱٫۲۵، رندر وقتی دیده می‌شود).
- «پروندهٔ صفر» یک برش عمودی کامل است (سه معما، نه یک بازی بلند). صدا فقط افکت‌های کوتاهِ موجود سایت است و پیش‌فرض ساکت.
- جارویس فقط تطبیق قطعی کلیدواژه است: عبارت‌های خیلی غیرمعمول را ممکن است نفهمد (در این حالت پیشنهاد می‌دهد دوباره بنویسید). سرویس‌ورکر/PWA اضافه نشد.
- محتوای تاریخی با قید عدم‌قطعیت نوشته شد ولی هنوز باید یک متخصص تاریخ ریاضیات بازبینی کند.

## تازه‌ها در نسخهٔ ۴
- **تاریخ ریاضیات تعاملی** (`/history`، `/history/<نام>`): هفت شخصیت به ترتیب اقلیدس، ارشمیدس، خوارزمی، خیام، فیثاغورس، نیوتن، امی نوتر. هر شخصیت با پس‌زمینهٔ خودش (`m1↔m11 … m7↔m77`)، تم رنگی، زندگی‌نامهٔ ساخت‌یافته و برچسب «مستند / منسوب»؛ در موبایل با لمس؛ کلیدهای ← → Esc. داده در `data/history.json` (فیلدهای اختیاری `video` و `chapters` برای ویدیوی آینده).
- **بازی‌های آموزشی** (`/games`): هشت بازی با مکانیک‌های متفاوت (دسته‌بندی ون، تخمین روی محور، پازل برهان، جفت‌یابی، مسابقهٔ زمان‌دار، ساخت خط روی صفحهٔ مختصات، انتخاب چندگانه، تنظیم حجم).
- **بانک نمونه‌آزمون** (`/exams`): ۳۰ آزمون (۲۴ فصلی، ۳ ترکیبی، نوبت اول، نوبت دوم، جامع) با پاسخنامهٔ جدا؛ هر کدام PDF (A4، راست‌چین، شمارهٔ صفحه) و Word (با معادلهٔ واقعی).
- **آزمون‌ساز معلم** با سربرگ کامل، چاپ آزمون و پاسخنامهٔ جدا، فایل HTML مستقل.
- **پاورپوینت‌ساز** با ۱۰ چیدمان (مفهوم، فرمول با کسر انباشته، مثال حل‌شده، گام‌به‌گام، مقایسه، نمودار ون/محور/مثلث قائم، تمرین، جمع‌بندی) و فرمول‌های واقعی (کسر، توان، رادیکال) بدون LaTeX خام؛ افزودن مثال راستی‌آزمایی‌شده از بانک.
- **فونت‌های شما** (Hamrah، DigiCraft، Fedra) در `assets/fonts` و `css/fonts.css`.

### نقش فونت‌ها و دلیل آن
هر سه فایل ارائه‌شده فقط در وزن بسیار سنگین (Black) هستند و برای متن بلند خوانا نیستند؛ پس طبق دستور «ابتدا بررسی کن»، متن جزوه و پاراگراف‌ها در Vazirmatn (فونت قبلی پروژه) ماند. **DigiCraft** → تیتر اصلی (h1) و شمارهٔ فصل‌ها؛ **Fedra** → زیرتیترها و عنوان کارت‌ها؛ **Hamrah** → برچسب‌های کوتاه (منو، دکمه، تب). نویسه‌های ناموجود در این فونت‌ها (مثل «—» و نمادهای ریاضی) خودکار از Vazirmatn/سیستم می‌آیند و فرمول‌ها با KaTeX نوشته می‌شوند. اگر خواستید نقش‌ها را عوض کنید فقط `css/fonts.css` را ویرایش کنید. فایل‌های اصلی شما دست‌نخورده در `assets/fonts` هستند (کنارشان نسخهٔ woff2 برای سرعت).

### تصاویر تاریخ ریاضیات
`m1 m3 m7` آلفای واقعی داشتند. در `m2 m4 m5 m6` الگوی شطرنجی «شفافیت» داخل خود تصویر پخته شده بود؛ پس‌زمینهٔ آن‌ها با روش رنگی جدا شد (لبه‌ها نرم‌شده) و همهٔ هفت پرتره به webp شفاف بهینه شد (`assets/history/m1..m7.webp`، پس‌زمینه‌ها `m11..m77.webp`). فایل‌های PNG اصلی در بستهٔ حجم نیامده‌اند.

### بانک آزمون: چطور ساخته و چقدر قابل اتکاست
سؤال‌ها با مولدهای برنامه‌نویسی‌شده (`lib/qgen.js`، `lib/qgen2.js`) و بذرهای ثابت ساخته می‌شوند و پاسخ هر سؤال با همان کد محاسبه می‌شود (نه نوشتهٔ دستی)؛ هر مولد یک راستی‌آزمایی عددی دارد و روی ۸۲٬۸۰۰ نمونه آزموده شد (`tests/qgen.test.js`). ۳۳ مولد دارای ۱۱–۱۲ نوع سؤال برای هر فصل‌اند. با این حال بازبینی انسانی معلم پیش از استفادهٔ رسمی توصیه می‌شود (در بازبینی داخلی یک خطای شیب خط و چند ابهام پیدا و برطرف شد).
- **دامنهٔ نوبت اول (فصل ۱ تا ۴)** از منابع ثانویهٔ آموزشی (مثل سری نمونه‌سؤال‌های «نوبت اول ریاضی نهم، فصل ۱ تا ۴») گرفته شد؛ برای **نوبت دوم** منابع ناهم‌خوان‌اند (کل کتاب یا فصل ۵ تا ۸). دامنه‌ها و ساختار آزمون جامع **تأیید رسمی نشده** و در برنامه با برچسب «دامنه نیازمند تأیید» نمایش داده می‌شوند. برای تغییر، `lib/exams.js` را ویرایش و `npm run build:exams` را اجرا کنید.
- فصل ۳ (استدلال و اثبات) سه برهان آماده دارد و بقیه به‌صورت مسئلهٔ عددی/مفهومی است.
- بازتولید فایل‌ها: `npm run build:exams` (نیاز: Python، `pip install weasyprint python-docx`، و pandoc). فایل‌های ساخته‌شده همراه بسته هستند و برای اجرای سایت لازم نیستند.

### محدودیت‌های شناخته‌شده (صادقانه)
- ظاهر بصری (انیمیشن‌ها، سه‌بعدی، چیدمان موبایل، بارگذاری فونت در مرورگر) در مرورگر واقعی دیده نشد؛ آزمون‌ها با jsdom و رندر PDF/PPTX با LibreOffice انجام شد.
- PPTX در PowerPoint واقعی باز نشد. در LibreOffice نماد √ به‌دلیل نبود فونت Cambria Math کمی بزرگ‌تر/جابه‌جا دیده می‌شود. فونت متن PPTX عمداً Tahoma است.
- فایل‌های Word معادلهٔ واقعی دارند ولی در Word واقعی دیده نشدند.
- هنوز ویدیویی تحویل نشده؛ کتابخانهٔ ویدیو و بخش ویدیوی هر شخصیت تاریخی «حالت خالی» دارد.
- تولید سؤال/اسلاید با DeepSeek هنوز با کلید واقعی آزموده نشده (فقط با سرور ساختگی)؛ خروجی هوش مصنوعی را معلم باید بررسی کند و اعتبارسنجی ریاضی خودکار فقط برای مثال‌های بانک انجام می‌شود.
- بازی‌ها با اجرای خودکار از ابتدا تا انتها آزموده شدند، اما حس بازی روی لمس واقعی ارزیابی نشد.

## تنظیم DeepSeek (هوش مصنوعی)
۱. در `.env`:
```
DEEPSEEK_API_KEY=کلید-شما
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
TEACHER_ACCESS_CODE=یک-کد-دلخواه      # اختیاری ولی توصیه‌شده
AI_RATE_PER_HOUR=20                    # سقف درخواست هر IP در ساعت
AI_DAILY_LIMIT=300                     # سقف کل روزانه
```
۲. سرور را دوباره اجرا کنید. در `/teachers` پیام «هوش مصنوعی فعال است» دیده می‌شود.

نکته‌ها: نام مدل را فقط از `DEEPSEEK_MODEL` عوض کنید (در زمان نگارش، مستندات رسمی `deepseek-flash` و `deepseek-v4-pro` را فهرست کرده است: <https://api-docs.deepseek.com/>). کلید فقط در سرور خوانده می‌شود و هرگز به مرورگر نمی‌رسد. روی سرور واقعی مقدار `TRUST_PROXY=1` را فقط پشت reverse proxy بگذارید.

### امنیت
کلید فقط از متغیر محیطی؛ `.env` در `.gitignore`؛ فقط فایل‌های پوشه‌های `assets css js data files` سرو می‌شوند (نه `.env`، `lib`، `server.js`)؛ CSP، `nosniff`، `X-Frame-Options`؛ بررسی Origin برای POST؛ حد حجم بدنه (۱۶ کیلوبایت)؛ اعتبارسنجی سخت‌گیرانهٔ ورودی و خروجی مدل؛ محدودیت نرخ هر IP و سقف روزانه؛ کد دسترسی معلم (اختیاری)؛ خطاها بدون افشای جزئیات یا کلید.

## افزودن محتوا
**ویدیو** — در `data/videos.json` (آرایه) رکورد اضافه کنید؛ کد برنامه تغییر نمی‌کند:
```json
{"id":"union-intersection","title":"اجتماع و اشتراک","description":"توضیح کوتاه","chapter":"sets","topic":"اجتماع",
 "thumbnail":"/assets/thumbs/union.webp","duration":"۰۴:۳۰","uploadDate":"2026-10-01","tags":["مجموعه"],
 "source":{"type":"youtube","id":"11نویسه‌ایدی"}}
```
`source.type`: `youtube` (با `id`) ، `aparat` (با `id` هش ویدیو) یا `file` (با `src` به `.mp4/.webm` در `/files/...` یا `https://`). ویدیو فقط با کلیک کاربر بارگذاری می‌شود. برای نسخهٔ ایستا پس از افزودن ویدیو دوباره `npm run build` بزنید (صفحهٔ هر ویدیو پیش‌رندر می‌شود).

**منبع دانلودی** — فایل را در `files/` بگذارید و در `data/resources.json` ثبت کنید: `{"chapter":"sets","title":"...","type":"PDF","size":123456,"href":"/files/xxx.pdf"}`.
**نمونه‌سؤال** — به `data/questions.json` اضافه کنید (`question` و `answer` به‌صورت HTML با فرمول `\( ... \)`).
**اطلاعات تماس** — `data/site.json` را پر کنید؛ تا خالی است هیچ اطلاعاتی نمایش داده نمی‌شود. برای فعال‌شدن فرم تماس `CONTACT_WEBHOOK_URL` را (آدرس سرویسی که JSON پیام را دریافت می‌کند) در `.env` بگذارید.
**بازتولید جزوه از Word** — `python3 tools/build-content.py فایل.docx` (جزوه و بانک سؤال) و `python3 tools/build-docx.py` (فایل‌های Word فصل‌ها؛ نیاز به pandoc).

## پنل معلمان
- **منابع:** دانلود فایل Word هر فصل و منابع ثبت‌شده.
- **بانک سؤال:** ۳۵ تمرین استخراج‌شده از جزوه همراه با پاسخ، فیلتر، چاپ، افزودن به آزمون. سطح دشواری در جزوه مشخص نشده و «تعیین‌نشده» نمایش داده می‌شود.
- **آزمون‌ساز:** ساخت از بانک، دستی، یا با هوش مصنوعی (فصل، تعداد، نوع، سطح، نمرهٔ کل، پاسخ‌نامه، بارم)؛ ویرایش کامل؛ خروجی: چاپ/PDF، TXT، JSON.
- **پاورپوینت‌ساز:** پیش‌نویس خودکار از جزوه (بدون AI) یا تولید با AI؛ ویرایش اسلایدها؛ ساخت فایل `.pptx` واقعی در مرورگر (PptxGenJS، راست‌چین، ۳ قالب رنگی). فرمول‌ها به متن یونیکد خوانا تبدیل می‌شوند (نه تصویر LaTeX). فونت پیش‌فرض Tahoma است.

## build و انتشار
**الف) با Node (همهٔ قابلیت‌ها، از جمله AI و فرم تماس):** روی هر هاست Node: `npm install --omit=dev && npm start` با `HOST=0.0.0.0`، `PORT` و `SITE_URL` و (پشت Nginx/Cloudflare) `TRUST_PROXY=1`. برای HTTPS از reverse proxy استفاده کنید.
**ب) هاست ایستا (Netlify، GitHub Pages، …):** `SITE_URL=https://دامنه npm run build` و پوشهٔ `dist/` را منتشر کنید. AI و فرم تماس نیاز به سرور Node دارند و در این حالت غیرفعال می‌مانند.

## SEO
عنوان/توضیح اختصاصی، canonical، Open Graph، JSON-LD (WebSite/Organization/BreadcrumbList، و VideoObject فقط برای ویدیوی واقعی)، `sitemap.xml` و `robots.txt` (فقط `/api/` بسته است)، HTML پیش‌رندرشدهٔ هر مسیر شامل متن جزوه برای خزنده‌ها. صفحات عمومی نیاز به ورود ندارند.
پیش از انتشار `SITE_URL` را بدهید. ثبت در Google Search Console با دسترسی شما: افزودن دامنه ← تأیید مالکیت ← ثبت `https://دامنه/sitemap.xml`. هیچ رتبه‌ای تضمین نمی‌شود.

## تست
`npm test` — ریاضی هسته، اعتبار ۸۶۳ فرمول با KaTeX، ۸۲٬۸۰۰ نمونهٔ مولد سؤال، ۲۲۴ بررسی بانک آزمون (ساختار، PDF/Word، بارم)، نگاشت تاریخچه، منطق بازی‌ها، ساخت PPTX و بررسی سرور (با سرور DeepSeek ساختگی محلی؛ هیچ درخواست واقعی ارسال نمی‌شود).
`npm i --no-save jsdom && npm run test:ui` — آزمون رابط: همهٔ مسیرها، ابزارها، جزوه‌ها، پنل معلمان، تاریخچه (۷ شخصیت)، و اجرای خودکار هر هشت بازی تا پایان.
